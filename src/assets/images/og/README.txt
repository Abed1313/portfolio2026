OPEN GRAPH / LINK PREVIEW IMAGE
===============================
Expected file:  og-image.png  (or .jpg / .jpeg / .webp; png or jpg recommended for social sites)
Recommended:    exactly 1200x630 px.
Used in:        link previews on LinkedIn, WhatsApp, X/Twitter, Slack, etc.
Fallback:       a default preview card is generated automatically at build time.

Accepted formats: .webp .jpg .jpeg .png  (if several exist, priority is webp > png > jpg > jpeg)
Missing files are fine: the site shows a fallback and the build never fails.
