PROFILE PHOTO
=============
Expected file:  me.webp  (or me.jpg / me.jpeg / me.png)
Recommended:    square, at least 800x800 px, face centred.
Used in:        About section photo card.
Fallback:       "AR" initials avatar.

Accepted formats: .webp .jpg .jpeg .png  (if several exist, priority is webp > png > jpg > jpeg)
Missing files are fine: the site shows a fallback and the build never fails.
