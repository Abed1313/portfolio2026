PROJECT IMAGES
==============
One folder per project (folder name = project id):
  aura-neurology/
  smart-home-system/
  red-triangle-property-marketplace/
  ev-management-system-api/
  dern-support-system/
  movie-library/
  adventure-quest-rpg/

Inside each folder:
  cover.*        card image, 1600x900 px (16:9)           optional
  1.*, 2.*, 3.*  gallery screenshots for the detail modal  optional (any count, sorted by number)

Fallback:       gradient or code-style placeholder with the title + tags.
Aura Neurology: real client. Only add screenshots that contain NO patient data.

Accepted formats: .webp .jpg .jpeg .png  (if several exist, priority is webp > png > jpg > jpeg)
Missing files are fine: the site shows a fallback and the build never fails.
